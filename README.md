# smart-employee-leave-attendance-system
Smart Employee Leave &amp; Attendance Management System built with Spring Boot, MySQL, JWT Authentication, Role-Based Access Control, Leave Workflow, Attendance Tracking, Leave Policies, Leave Balances, Manager Approvals, and Face Recognition Attendance Integration.


Smart Employee Leave & Attendance Management System is a full-stack workforce management application designed to streamline employee operations within an organization.

The system provides secure JWT-based authentication and role-based access control for Admins, Managers, and Employees. Employees can create profiles, apply for leaves, view leave balances, and track attendance. Managers can review team attendance, approve or reject leave requests, and monitor employee activities. Administrators can configure leave policies, holidays, and organizational settings.

The project also includes an event-based attendance architecture designed for face recognition integration, allowing employees to mark attendance through facial recognition while maintaining accurate working-hour calculations and attendance summaries.

Key Features:
• User Authentication & Authorization (JWT)
• Employee Profile Management
• Leave Request & Approval Workflow
• Leave Policies & Leave Balance Management
• Holiday Management
• Attendance Tracking & Working Hour Calculation
• Team Attendance Dashboard
• Face Recognition Attendance Integration
• RESTful APIs with Spring Boot
• MySQL Database Integration
• Role-Based Access Control (Admin, Manager, Employee)

Technology Stack:
• Java 17
• Spring Boot
• Spring Security
• JWT Authentication
• MySQL
• JPA/Hibernate
• Maven
• Python (Face Recognition Module)
